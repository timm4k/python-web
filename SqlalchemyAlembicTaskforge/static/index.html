Downgrade

Run copied commands in the project terminal with .venv active and DATABASE_URL set — upgrade applies every missing revision up to the target

The application needs the complete schema — run alembic upgrade head before starting it, and explore earlier revisions only in a disposable database

Rollback runs with alembic downgrade -1 in the terminal — removing tables or columns also removes their data, so use a disposable database for practice
